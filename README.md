# Xray VLESS Reality for Alpine Linux (Ultra-Lightweight & Zero-Log)

[English](#english) | [Turkce](#turkce)

---

## English

An automated installation script to set up Xray-core VLESS + XTLS-Reality on Alpine Linux, specifically tailored for low-resource environments (512 MB RAM & 1 vCPU) with a strict zero-log privacy policy.

### Features

- Ultra-Low Memory Footprint (~15 - 25 MB RAM):
  - GOMAXPROCS=1: Locks Go runtime threads to a single core, eliminating CPU scheduling overhead.
  - GOGC=20 & GOMEMLIMIT=350MiB: Aggressive garbage collection prevents OOM (Out-Of-Memory) crashes.
  - Custom bufferSize: 16 KiB: Prevents memory ballooning during concurrent data transfers.
  - Traffic counters and extraneous protocol analyzers are disabled.
- Zero-Log Privacy:
  - loglevel: "none" configured in Xray.
  - OpenRC standard output and errors are redirected to /dev/null. No access or error logs are written to the disk.
- Camouflage (SNI: Speedtest):
  - Disguised as www.speedtest.net (supporting TLS 1.3 & HTTP/2).
- Automated Key Generation:
  - Automatically generates x25519 keypair (Private/Public Key), UUID, and Short ID.
- Native OpenRC Integration:
  - Installs as a native Alpine OpenRC service and starts automatically on boot.
- QR Code & Share Link:
  - Instantly generates an ASCII QR code in your terminal and exports the vless:// configuration link.
- Multi-Language Support (Auto-Detect):
  - Prioritizes keyboard layout and system locale to display in Turkish on Turkish systems and English on all other systems (supports manual override via `XRAY_LANG=tr` or `XRAY_LANG=en`).

### Quick Start

Connect to your Alpine Linux server via SSH as root and run:

```sh
# Download and run in one step
curl -sSL -o install.sh https://raw.githubusercontent.com/xmtaha/xray-auto/main/install.sh
chmod +x install.sh
./install.sh
```

Installation takes approximately 10-20 seconds. Once finished, configuration details and the import QR code will be displayed.

### Service Management (OpenRC)

Manage the Xray service using standard OpenRC commands:

```sh
# Check service status
rc-service xray status

# Restart the service
rc-service xray restart

# Stop the service
rc-service xray stop

# Start the service
rc-service xray start

# View client credentials anytime
cat /etc/xray/client_info.txt
```

### Verification

```sh
# Verify memory consumption (~15-25 MB RSS)
ps -o pid,user,%mem,rss,args -C xray

# Verify that no log files exist on disk
ls -la /var/log/xray 2>/dev/null || echo "No log files found."
```

## Turkce

Alpine Linux uzerinde Xray-core VLESS + XTLS-Reality protokolunu tek komutla kuran, 512 MB RAM ve 1 vCPU sunucular icin ozel olarak optimize edilmis, tamamen sifir log (zero-log) prensibiyle calisan kurulum araci.

### Ozellikler

- Ultra Dusuk RAM Tuketimi (~15 - 25 MB):
  - GOMAXPROCS=1: Go calisma zamanini tek cekirdege kilitler, gereksiz thread ve baglam degisimini engeller.
  - GOGC=20 & GOMEMLIMIT=350MiB: Agresif bellek temizleme (GC) ile VPS cokmesini (OOM) onler.
  - Xray bufferSize: 16 KiB: Coklu eszamanli baglantilarda RAM sismesini engeller.
  - Trafik sayaclari ve gereksiz ayristirma modulleri bellek tasarrufu icin kapatilmistir.
- Tamamen Sifir Log (Zero-Log & Gizlilik):
  - Xray yapilandirmasinda loglevel: "none" ayarlanmistir.
  - OpenRC servis ciktilari dogrudan /dev/null adresine yonlendirilir. Diskte hicbir erisim veya hata kaydi tutulmaz.
- Modern Kamuflaj (SNI: Speedtest):
  - www.speedtest.net (TLS 1.3 & HTTP/2) uzerinden trafik maskeleme.
- Otomatik Anahtar Uretimi:
  - x25519 anahtar cifti (Private/Public Key), UUID ve Short ID kurulum sirasinda otomatik uretilir.
- OpenRC Entegrasyonu:
  - Alpine Linux yerel init sistemi olan OpenRC servisi olarak kurulur ve sistem acilisinda (boot) otomatik baslar.
- QR Kod ve Paylasim Linki:
  - Kurulum sonunda dogrudan terminalde okutulabilir QR kod ve vless:// baglanti linki uretir.
- Coklu Dil Destegi (Otomatik Algilama):
  - Klavye duzeni ve sistem dilini oncelikli olarak baz alir; Turkce sistemlerde Turkce, diger tum sistemlerde varsayilan olarak Ingilizce acilir (`XRAY_LANG=tr` veya `XRAY_LANG=en` ile de zorlanabilir).
